# Aurora Coast

> Fictional demonstration data

**Chapter One: Ten Days in Transit** follows a deliberately fictional journey from 18–27 July 2027:

Ljubljana → Afterlight Fields → Venice → Piran → Vienna → Berlin

The bundle contains exactly 12 synthetic music records and 8 fictional life events. Every song, artist, person, note, identifier, and timestamp was written for this public demonstration. Afterlight Fields is not a real festival.

The files share the exact revision `aurora-coast-r1-2027-07`. Storywalker Studio validates that revision and the expected record counts before showing a memory-only preview. Nothing is persisted until the Author chooses the explicit seed action.

Run the deterministic fixture check with:

```bash
npm run demo:aurora-coast
```

See [the demo-data note](../../docs/demo-data.md) for construction and de-identification boundaries.
