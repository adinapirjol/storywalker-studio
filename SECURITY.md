# Security

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/adinapirjol/storywalker-studio/security/advisories/new).

Do not open a public issue containing credentials, private journey data, provider exports, or a path to sensitive local files.

Storywalker Studio is a portfolio-grade local demonstration, not a production identity or archival service. Its browser persistence is not encrypted or durable. Spotify import is optional, local, and excluded from the browser bundle.

Supported security fixes target the latest `main` branch.
