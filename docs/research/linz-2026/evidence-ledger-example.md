# Evidence-ledger example

| Field | Example |
| --- | --- |
| Proposal ID | `linz-echo-02` |
| Source records | Festival event ID; City data record ID; local trace ID |
| Time / zone | `2026-09-09`, Europe/Vienna, approximate |
| Location / precision | Hauptplatz, generalised |
| Relationship | Spatial |
| Certainty | Low |
| Missing information | No source geometry in demo; private location generalised |
| Transformations | Named-place grouping → interpretive proposal |
| Current Author decision | Refused |

Recorded means directly present in a source. Inferred is calculated/suggested. Authored is written or explicitly approved by the traveller. Refused retains a correlation while rejecting its proposed interpretation. No state changes automatically.
