# Storywalker: Public City, Private Echoes

> A city can record what happened where. Platforms can record where the traveller went and what they heard. An adaptive system can propose relationships between those traces—but it cannot decide what the experience meant.

The traveller is the Author; the AI is the Editor—and every edit remains negotiable.

This is Storywalker Prototype 1: a bounded Linz research experiment, not a new application or installation claim. Its path is **public place → private trace → proposed meaning → human negotiation → locative echo**.

## What works now

- `/research/linz` is a deterministic three-location simulated interaction with Accept, Revise and Refuse, a visible ledger, and a safe portable manifest export.
- Festival programme records and three versioned City of Linz parking-meter fragments are public; private cards in this build are labelled synthetic.
- Local Spotify/Timeline minimisation, exactly-three selected-trace validation, and a street-history join routine have tests.

## What is local or planned

- Three selected low-stakes Author records stay in ignored local files; none are provided or implied by this repository.
- Before travel, re-check the City release and replace the selected source records only if a newer verified extract is deliberately chosen.
- No live AI, live GPS or copyrighted Spotify audio is required for the 90-second route.
