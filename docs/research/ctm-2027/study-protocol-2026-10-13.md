# Listening Again capture and reflection protocol

13 October 2026. Proposed protocol; no Author observations or participant outcomes are recorded here.

## Reproducible 75 second demonstration

Use the existing local browser app at `/research/refusal`, a fresh page session and only the labelled Aurora Coast fixture. Do not open Vault windows, select local files or show saved private notes in a public recording. Start silent; headset optional. All choices use native buttons, Tab and Enter/Space. Range volume supports arrow keys. Page text supplies a complete equivalent; screen capture should include readable captions.

| Time | Action and explanation |
|---|---|
| 0–15 seconds | Open source details. Read encounter versus playlist and unknown selection context. Describe the three spatial positions. |
| 15–25 | Accept. Explain endorsement of a relationship, not factual acceptance. Optionally Play briefly at low volume, then Stop. |
| 25–40 | Enter fictional wording: “This was tiring; I do not need a resilience story.” Revise. Point to the changed wording and marked connection. Optionally audition and pause/resume. |
| 40–55 | Refuse. Show the gap and retained sources/history. Silence is an editorial boundary, not punishment. |
| 55–65 | Leave unresolved. Show the dotted unanswered relationship and textual distinction from refusal. |
| 65–75 | Inspect dated readings. Explain that a real return on a later date is still pending, and that no wording must be made public. |

Capture instructions: keep notifications off, frame only the fictional study, use the recorder of your choice, and review the resulting 60–90 second file for readable text and accidental private content. Record only original oscillator audio or use silence. No video has been generated by this protocol. Save an actual recording privately until separately approved for release.

## Author session and later revisit

1. Choose silent/text-only or quiet audio, and stop at any time. No response deadline.
2. Read the fixed proposal and source limits; try one or more decisions without needing a reason.
3. Optionally save an encrypted notebook snapshot. Repeat the identical save to verify it returns the same record; do not enable a scene association unless wanted.
4. On a later date, load saved sessions and compare a new reading. Earlier snapshots remain visible alongside current actions; interactive state is not automatically restored. Record disagreement without harmonising it.
5. Keep actual reflections private. A public extract requires separate Author review and release permission.
