## A field of references

The new private route `/research/arena-field` experiments with juxtaposition. A channel's arranged order becomes an orbit. The Author can inspect a source, hold two references together, set material aside and add a composition note. None of these acts changes the source channels or asserts semantic similarity.

Authenticated Are.na MCP reads supply a minimised local snapshot. The app imports that staging file into the encrypted Vault only after an unlocked, same-origin request, then removes the staging file. Refreshes archive the earlier snapshot and composition. Private content is absent from the public page shell; images contact their original host only after an explicit request. This is a bounded snapshot workflow, not background synchronisation. The existing public reader remains separate and continues to withhold unavailable/private sources.
