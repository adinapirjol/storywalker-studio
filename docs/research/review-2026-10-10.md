## Changes reviewed and repaired

- Existing Vault access now uses the same passkey / recovery-passphrase modal as
  other private pages. Authentication transport, device ceremonies, rendering and
  session policy have separate owners. Import actions use the session rather than
  forwarding a page's recovery passphrase.
- Sessions rotate on unlock. Cancellation closes an already-opened Vault without
  issuing a replacement session. Async private routes recheck authority before
  persistence and release; expired work cannot silently replay a provider call.
- Native evidence acceptance validates every retained chunk before one atomic
  save. Missing chunks cannot leave a partially accepted batch.
- Passkeys verify real synthetic signatures, user verification, relying-party
  origin, counters and one-use challenges. PRF wraps the existing encrypted Vault
  key. Enrollment/removal retain current authority; pending unlocks cannot use
  removed credentials. Credential storage rejects symlinks and competing writers.
- Request readers bound bytes before decoding and release readers on cancellation.
  The Python adapter bounds output and avoids repeated accumulated-buffer copies.
  Browser file imports read sequentially, with limits on file count and the full
  selection. These are boundedness improvements, not measured latency benchmarks.
- Private career notes, the prior review inventory and machine signing settings
  now live beneath ignored `private-data/`. Existing credentials, Vault storage,
  raw inputs and local runtime folders remain ignored at their required locations.
  The native project uses an optional local signing include, with no team value in
  public configuration. The public audit also checks native signing text and
  rejects private notes and provisioning/credential file paths.
- Aurora Coast contains paused, manually explored fictional companion, batch
  timing, threshold and access-boundary examples. Its transport is simulated and
  cannot export real research events. Nine examples are checked against the local
  production Pydantic evaluator, including duplicates, gaps and Watch preference.
- [Code review guidelines](../code-review-guidelines.md) are linked from AGENTS.md.
  They cover focused modules, explicit policy ownership, proportionate design
  patterns, bounded streaming/iteration and security/privacy acceptance criteria.
